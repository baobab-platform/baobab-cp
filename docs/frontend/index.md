# CP Console (frontend)

The CP Console is the administrative frontend defined by ADR-BCP-019. It lives in `frontend/`; see
`frontend/README.md`.

- [FE-00: discovery and architecture lock](fe-00-architecture-lock.md): the route map, authority, readiness and
  contract matrices, the gap list, the BFF threat model, risks and the gate sequence.
- FE-01 foundation: tooling, configuration, image and CI (`frontend/README.md`).
